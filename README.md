## 🚀 Featured Projects

- **[RAG Document Pipeline — Clinical Data Extraction](https://github.com/Tejesh18/RAG-Assistant)**  
  End-to-end retrieval pipeline at **VCU Health** — ingests unstructured clinical slide images, extracts structured metrics via **Claude Vision API**, feeds clean outputs into an **XGBoost classifier** for uroflowmetry waveform classification. Targeting ~85% accuracy across six clinical categories.

- **[Personal Identifiable Information (PII) Data Masker](https://github.com/Tejesh18/Personal-Identifiable-Information-PII-Data-Masker)**  
  AI-powered privacy tool using **spaCy + OpenCV + Flask** that detects and masks PII in text and images across **100K+ records**. Reduced manual review by 40%.

- **[AI Enterprise Automation System](https://github.com/Tejesh18/AI-Enterprise-Automation-System)**  
  Agentic RAG assistant using the **Claude API** — ingests bid and project data, builds a retrievable knowledge layer, and generates natural language responses for pipeline status, deadline risks, and follow-up drafts.

- **[Inventory Forecasting & Management System](https://github.com/Tejesh18/Inventory-Forecasting-and-Management-System)**  
  Database-driven forecasting system using **Flask, MySQL, and ARIMA/RF models** to predict inventory demand and optimize stock levels.
