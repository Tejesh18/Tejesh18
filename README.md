## 🚀 Featured Projects  

- **[RAG Assistant – Retrieval-Augmented Chatbot](https://github.com/Tejesh18/RAG-Assistant)**  
  Built an AI agent using **LangChain + OpenAI API + Chroma DB + Streamlit** for **document-based Q&A**.  
  Implements **RAG architecture**, **chat-history reformulation**, and **multi-PDF support** for context-aware answering.  

- **[Personal Identifiable Information (PII) Data Masker](https://github.com/Tejesh18/Personal-Identifiable-Information-PII-Data-Masker)**  
  AI-powered privacy tool using **spaCy + OpenCV + Flask** that detects and masks PII in text and images.  
  Integrates easily into enterprise pipelines for **data governance and compliance**.   

- **[Inventory Forecasting & Management System](https://github.com/Tejesh18/Inventory-Forecasting-and-Management-System)**  
  Database-driven forecasting system using **Flask, MySQL, and ARIMA/RF models** to predict inventory demand and optimize stock levels.
